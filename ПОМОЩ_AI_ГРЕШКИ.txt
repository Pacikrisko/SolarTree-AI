SOLARTREE AI 0.3.2 — корекция на грешките в AI чата

ПРОМЯНА:
Сървърът вече показва ясна причина за неуспешна OpenAI заявка,
вместо общото „AI услугата не отговори“.
Статусът в интерфейса вече гласи „API ключът е настроен“,
защото наличен ключ не означава доказано успешна API връзка.

НАЙ-ЛЕСНА АКТУАЛИЗАЦИЯ:
1. Затвори backend прозореца, в който работи uvicorn.
2. Копирай следните 3 файла от новия архив в СТАРАТА папка на проекта:
   - backend/app/assistant.py
   - backend/app/main.py
   - frontend/src/App.tsx
3. НЕ заменяй backend/.env или backend/solartree.db (съдържат настройки и данни).
4. Стартирай отново start_backend_windows.bat и frontend.
5. Изпрати съобщение на асистента. Ще се появи конкретна причина.

ПРОВЕРКИ:
- В backend/.env: OPENAI_API_KEY=твоят_ключ, OPENAI_MODEL=gpt-4.1-mini
- Не добавяй ключа в React или във frontend/.env.
- Ако получиш грешка 429, провери API Billing/Usage/Limits.
  ChatGPT Plus не заплаща автоматично OpenAI API заявките.
- Ако грешката е 401, ключът е грешен/отменен/изтекъл.
- Ако е 404, провери името на модела и достъпа на API проекта.
- Ако е 403, провери правата на ключа и проекта.

Никога не изпращай и не публикувай реалния си API ключ.
Тази версия не доказва, че има активен кредитен баланс; това се проверява
само чрез успешна заявка към OpenAI API.
